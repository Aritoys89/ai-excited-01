A colossal turquoise ocean wave curls over into the shape of a roaring
lion's head — a foam mane, fanged jaws wide open, golden sunlight shining
through them — while a tiny red surfer rides deep inside the barrel. The
whole scene is one moment of momentum: the wave is about to break, and the
surfer is already inside it.

`main.py` (standard library only) checks the bundled artwork `art.jpg` is
a real JPEG inside the size caps, then writes it to `/output/entry.png`.

## Run it

```sh
python3 main.py
# writes /output/entry.png (1024x683 JPEG, 237107 bytes)
```
